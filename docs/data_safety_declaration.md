# Google Play データセーフティ申告メモ

Google Play Console「アプリのコンテンツ → データセーフティ」セクションでの回答用メモ。

申告と実装が一致していないと enforcement action（警告・公開停止）の対象になるため、慎重に。

---

## 1. データの収集・共有の概要

### Q: アプリはユーザーデータを収集または共有していますか？
**A: はい**

### Q: 収集されるデータはすべて送信中に暗号化されていますか？
**A: はい**（Firebase / RevenueCat / AdMob はすべて HTTPS 経由）

### Q: ユーザーがデータの削除をリクエストする方法を提供していますか？
**A: はい**
- アプリ内「データを全て削除」（端末内データ）
- アプリ削除（Android 内データすべて消去）
- 問い合わせメールで RevenueCat データ削除依頼

---

## 2. 収集するデータ種別

各項目について「収集する/しない」「目的」「データ収集元（ユーザー入力 or 自動）」「収集が任意か必須か」「ユーザーへの開示」を答える。

### 収集するデータ

| データ種別 | 収集するか | 目的 | 収集元 | 任意/必須 | 共有先 |
|----------|---------|-----|-------|---------|------|
| **写真と動画** | ✅ する（端末内のみ） | アプリの機能（免許証作成） | ユーザー入力 | 任意 | 共有なし |
| **個人ID（広告ID）** | ✅ する | 広告 | 自動収集 | 必須 | Google AdMob |
| **アプリの操作 / アプリ内検索履歴** | ❌ しない | - | - | - | - |
| **クラッシュログ** | ✅ する | 分析（アプリの安定性向上） | 自動収集 | 必須 | Firebase Crashlytics |
| **診断情報（端末モデル・OS）** | ✅ する | 分析 | 自動収集 | 必須 | Firebase Crashlytics |
| **アプリのパフォーマンス** | ❌ しない | - | - | - | - |
| **購入履歴** | ✅ する | 購入機能 | ユーザー操作 | 必須（プレミアム購入時） | RevenueCat |
| **メール アドレス** | ❌ しない（任意の問い合わせのみ、アプリ内では収集しない） | - | - | - | - |
| **位置情報** | ❌ しない | - | - | - | - |
| **連絡先** | ❌ しない | - | - | - | - |
| **氏名・電話番号** | ❌ しない（NFCタグへの書込はユーザー手元、サーバー送信なし） | - | - | - | - |
| **正確な位置情報** | ❌ しない | - | - | - | - |
| **おおよその位置情報** | ⚠️ 自動（AdMob が国レベルの位置情報を取得する場合あり）| 広告 | 自動 | 必須 | Google AdMob |

### 詳細補足（Play Console での回答時のテキスト）

#### 写真と動画
- **収集する**: ペット写真（端末内のみ、外部送信なし）
- **目的**: アプリの機能（免許証カード生成、NFCタグ書込み代行時のみGoogleフォーム経由で受領）
- **収集元**: ユーザーが選択
- **任意/必須**: ユーザーが任意で選択
- **共有先**: 共有しない（端末内処理のみ）
- **オプション**: 写真権限を拒否すれば収集されない
- **削除リクエスト**: アプリ内「データを全て削除」 or アプリ削除

#### 広告ID（AD_ID）
- **収集する**: GAID（Google 広告 ID）
- **目的**: 広告
- **収集元**: 自動
- **任意/必須**: 必須（無料ユーザーのみ。プレミアム購入で広告非表示）
- **共有先**: Google AdMob
- **オプション**: プレミアム購入で広告停止 / 端末設定で広告ID削除可能

#### クラッシュログ + 診断情報
- **収集する**: アプリのクラッシュ情報、端末モデル、OS バージョン
- **目的**: 分析（アプリの安定性向上）
- **収集元**: 自動
- **任意/必須**: 必須
- **共有先**: Firebase Crashlytics（Google）
- **暗号化**: 送信中に HTTPS 暗号化
- **削除リクエスト**: 問い合わせメール経由

#### 購入履歴
- **収集する**: アプリ内購入の履歴、プレミアム状態
- **目的**: 購入機能
- **収集元**: ユーザー操作
- **任意/必須**: 必須（購入時のみ）
- **共有先**: RevenueCat（Apple/Google の購入レシート検証用）

## 3. 補足事項

### 収集していないと明示すべきもの
- 連絡先（電話帳、SNS等）
- カレンダー
- ファイル/ドキュメント
- 音声/会話
- ヘルスケア・フィットネス
- 金融情報（決済はストア経由なのでアプリでは収集しない）

### NFC機能のデータ取り扱い
NFCタグへの書き込みデータ（ペット名・飼い主名・電話番号など）は：
- ユーザーがアプリ内で入力 → そのまま NFC タグに書き込み
- 当方サーバーには送信されない
- → **データ収集に該当しない**（と判断）

NFC書き込み代行サービス（Googleフォーム）の場合：
- ユーザーが Google フォームに入力 → 飼い主名・電話番号・ペット名・写真がしゅーとに送信される
- 書き込み完了後にしゅーとがフォーム回答を削除
- → これは「アプリ外」の流れなので、データセーフティ対象外（と判断）

## 4. データの利用目的別カテゴリ（Play Console の選択肢）

申告時に「データの利用目的」で選ぶカテゴリ：
- **アプリの機能** ← 写真と動画
- **分析** ← クラッシュログ、診断情報
- **広告** ← 広告ID、おおよその位置情報
- **購入機能** ← 購入履歴
- **アカウント管理** ← なし
- **デベロッパーへの連絡** ← なし
- **不正行為防止、セキュリティ、コンプライアンス** ← なし
- **パーソナライズ** ← なし

---

## 5. 申告時の注意事項

1. **iOS App Store の申告と一貫性を保つ**（矛盾するとレビューで指摘される）
2. **広告ID は無料ユーザーのみだが「収集する」と申告**（プレミアム購入で停止できると注釈）
3. **Firebase Crashlytics は「分析」カテゴリ**（「アプリの機能」ではない）
4. **位置情報はおおよそのみ、正確な位置情報は不可**（AdMob のデフォルト動作）
5. **NFC書き込み代行はGoogleフォーム経由なので、本アプリのデータセーフティ対象外**

---

## 6. 申告後の運用

- **コードと申告が一致しているか定期確認**（特に新機能追加時）
- アップデートで新たに収集するデータが増えたら**必ず再申告**
- Google からの enforcement 通知は迅速に対応（72時間以内推奨）
