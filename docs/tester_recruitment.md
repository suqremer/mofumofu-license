## 5. フィードバック収集 Google フォーム項目案

### フォームタイトル
「うちの子免許証 Android テスト フィードバック」

### 項目

#### 1. 基本情報（必須）
- お名前（イニシャル可）
- お使いのAndroid端末（機種名）
- Androidバージョン

#### 2. 全体評価（必須）
- アプリ全体の使いやすさ（5段階評価：1=使いにくい / 5=使いやすい）
- 動作の安定性（5段階評価）

#### 3. 機能別評価（必須、各5段階）
- 免許証作成のスムーズさ
- 写真選択・編集
- コスチューム着せ替え
- 完成画像の見栄え
- NFC機能（使った場合のみ）
- アプリ起動速度

#### 4. 詳細フィードバック（必須）
**発見したバグや不具合があれば、できるだけ具体的に教えてください**
（自由記述、最低50文字以上）

例：「写真選択画面で◯◯機種だと縦横が崩れる」「免許証作成で背景削除が3秒くらいかかる」など

#### 5. 改善要望（必須）
**「こうだったらいいな」と思った点を3つまで教えてください**
（自由記述、最低30文字以上）

#### 6. 良かった点（任意）
**特に気に入った機能・気持ちよかった操作があれば教えてください**

#### 7. 友人に勧めたいか（必須）
- このアプリを Android使ってるペット飼いの友人に勧めたい？（5段階評価：1=勧めない / 5=絶対勧める）

#### 8. その他（任意）
**自由記述スペース**

## 6. 製品版申請の質問への回答ドラフト（テスト終了後に書く）

Google が求める「テスト中にどんなフィードバックを得て、何を変更したか」への回答は具体的に。

### テンプレート

```
▼テスト中に得たフィードバック（具体的に3件以上）
1. 〇〇機種で△△画面が崩れる → 対応: ××で修正
2. 起動時間が長いとの指摘 → 対応: 並列化処理で1〜2秒に短縮
3. NFCの「かざすだけ読み取り」の説明文がiOS前提だった → 対応: Android向け文言に修正

▼バグ修正
- ONNX Runtime のクラッシュ → ProGuardルール追加で解消
- 写真パス処理がAndroid環境で動作しない問題 → PathResolver改修で対応

▼テスト中に行ったコード変更（コミット履歴抜粋）
- commit b436635: 写真パス処理を Android 対応化
- commit 4dd5b00: Android リリースビルド対応
- commit 8e62169: NFC UI 文言を OS 別対応
- commit c790410: 起動高速化 + UX 改善
- commit e228efa: 免許証画像の文字位置を OS 別に調整

▼テスター
12名以上のテスターが14日間継続してアプリを使用しました。
全員から定性的なフィードバックを Google フォーム経由で収集し、
具体的な改善点を反映してからこの申請に至ります。
```

**重要**: 抽象表現（「アプリを改善した」「バグを直した」のみ）はNG、却下対象。
